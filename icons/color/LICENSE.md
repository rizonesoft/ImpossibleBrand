# Colour Icons: License Notice

The colour icons in this directory are original Impossible OS artwork, authored on 2026-09-27 and licensed under **GPL-3.0-only** like the rest of the repository (see [LICENSE](../../LICENSE)).

- **Sources:** SVGs in [`icons/src/`](../src/), one file per icon on a 48x48 grid. All are hand-written except `recycle_bin_full.svg`, which is generated by the OS's `scripts/site/gen_recycle_bin_full.py` (OS commit `75c468c32`) until that generator moves here.
- **Rasters:** the PNGs in `16/` through `256/` are rendered from those sources and committed, so a build never needs an SVG renderer. Impossible OS packs them into `icons.ires` at build time.
- **Spec:** the grid, palette, light direction and small-size rules are in [docs/icons.md](../../docs/icons.md).

The Icons8 colour icons this directory used to reference (paid license, not redistributable as standalone files) are no longer used and are no longer present on `main`.
